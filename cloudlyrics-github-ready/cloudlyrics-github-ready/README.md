# CloudLyrics Studio

A React + Vite application packaged for GitHub and Vercel deployment.

## Requirements
- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository into Vercel, or connect the existing Vercel project to this GitHub repository.

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`

If this project is inside a subfolder in a larger repository, set Vercel's Root Directory to that subfolder.
